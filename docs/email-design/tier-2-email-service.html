The Tier-2 upgrades that matter
Kafka event spine. Every state change is an immutable event. Analytics, billing, ML, and the reputation controller are independent consumers - no more everyone hammering Postgres. Replayable, ordered per partition.
Per-ISP adaptive throttling. Dispatch keeps a separate queue + token bucket per receiving domain (gmail.com, yahoo, outlook…). The controller watches 4xx deferrals and dynamically slows the offending ISP instead of the whole send. This is the single biggest deliverability lever.
IP pools + warm-up automation. Segregate transactional vs marketing IPs; ramp new IPs on a schedule; auto-rotate away from any IP whose reputation dips. Dedicated IPs for big senders.
Feedback loop closed. Bounces (SMTP 5xx), complaints (FBL/ARF), and unsubscribes flow back into the suppression list in near-real-time so the next send already excludes them.
Real-time analytics. Events stream into ClickHouse/Druid; campaign dashboards refresh in <5 min instead of a nightly batch. A/B winners can be picked mid-flight.
Multi-region active-passive. Second region streams Kafka + DB replicas. Failover in minutes; no data-center outage stops mail.

Remaining gaps (why you'd go to Tier 3)
▸ Active-passive wastes the standby region and still has a failover gap (minutes of downtime, possible data loss on the passive lag).
▸ Throttling is reactive. You slow down only after ISPs push back - no prediction, no send-time optimization per recipient.
▸ One big blast radius. A bad deploy or poison campaign can degrade the whole platform; no cell isolation.
▸ Deliverability + engagement are rules, not ML. No content scoring, no per-user optimal send time, no churn/inactive pruning model.
Bottom line
Tier 2 is a real production email platform: service-per-domain, a Kafka spine that decouples every consumer, closed feedback loops, real-time analytics, and - critically - per-ISP adaptive throttling with managed IP reputation. It hits 99.9% and deliverability becomes an engineering discipline. It's still active-passive, reactive on throttling, and has one blast radius - that's what Tier 3 fixes.
