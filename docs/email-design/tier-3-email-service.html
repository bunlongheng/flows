The send pipeline, upgraded
ML send-time optimization (STO). A per-subscriber model predicts the hour each person is most likely to open. The 500M blast is spread across each recipient's optimal window instead of all-at-once - lifts engagement and smooths ISP load naturally.
Predictive throttling. The reputation controller doesn't wait for 4xx deferrals - a model forecasts each ISP's tolerance from historical deferral curves, time of day, and current reputation, and paces ahead of the throttle. Reactive backoff stays as a safety net.
Engagement-based sending + list hygiene. Inactive addresses (no opens in N months) are throttled or pruned automatically. ISPs weight engagement heavily; mailing dead addresses is the fastest way to the spam folder. A model scores every address's inbox-placement risk pre-send.
Exactly-once effect. Idempotency keys + a dedup store (per cell) + transactional outbox from Render→Dispatch guarantee no subscriber gets a campaign twice, even across retries and failovers.
Edge rendering + tracking. Personalization and open/click tracking run at CDN edge PoPs near the recipient - sub-100ms pixel logging, and the origin never sees tracking traffic.
Tiered storage + streaming lakehouse. Hot (Cassandra/ScyllaDB, days) → warm (ClickHouse, weeks) → cold (S3/Iceberg, years). Flink jobs power real-time dashboards, anomaly detection, and model features off one event stream.
Reliability, security & compliance
✓ Active-active, no standby waste. Every cell serves live traffic; losing a region reroutes its tenants to healthy cells. RTO seconds, RPO ~0 for control-plane state.
✓ Continuous chaos + game days. Kill a cell, a broker, an IP pool in prod on purpose; auto-recovery is proven, not hoped.
✓ GDPR / CAN-SPAM / CASL by design. Per-region data residency (EU data stays in EU cells), one-click unsubscribe honored globally in seconds, right-to-erasure jobs, full consent audit trail.
✓ DKIM/SPF/DMARC + BIMI + TLS/MTA-STS. Full auth stack; BIMI shows the brand logo in inbox; enforced transport encryption.
✓ Multi-tenant fairness. Per-tenant quotas + weighted fair queuing so no single sender starves others or drags a shared IP's reputation.

Bottom line
Tier 3 treats the platform as a fleet of identical, isolated cells running active-active across regions, with ML doing the heavy lifting on the two things that actually decide email success at 500M scale: deliverability (predictive per-ISP pacing, engagement-based hygiene, send-time optimization) and reach without harm (blast-radius isolation, compliance by design). Nothing here is speculative - it's the shape of a real hyperscale ESP. The cost is real operational complexity, so you only earn it once Tiers 1-2 are genuinely maxed out.
